## Radio Settings (North East UK)

| Setting | Value |
|---------|-------|
| Frequency | **869.618 MHz** |
| Bandwidth | **62.5 kHz** (narrow) |
| Spreading Factor | **SF8** |
| Coding Rate | **5** |
| Mode | Narrow preset |

Set with: `set freq 869.618` and `set radio 869.618,62.5,8,5`
